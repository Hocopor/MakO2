# Структура файлов проекта лендинга психолога

## Директории и файлы

```
project/
├── index.html                    # Основной HTML файл
├── css/
│   ├── variables.css            # CSS-переменные (дизайн-система)
│   ├── reset.css               # Сброс стилей
│   ├── base.css                # Базовые стили
│   ├── components.css          # Компоненты (кнопки, карточки, формы)
│   ├── layout.css              # Сетка и расположение
│   ├── sections.css            # Стили секций
│   ├── responsive.css          # Медиа-запросы
│   └── utilities.css           # Вспомогательные классы
├── js/
│   ├── main.js                 # Основная логика (меню, инициализация)
│   ├── validation.js           # Валидация формы
│   ├── animations.js           # Анимации при скролле
│   └── form-submit.js          # Отправка формы
├── images/                     # Изображения
│   ├── hero-image.jpg          # Герой-изображение
│   ├── psychologist-photo.jpg # Фото психолога
│   ├── service-1.svg           # Иконка услуги 1
│   ├── service-2.svg           # Иконка услуги 2
│   ├── service-3.svg           # Иконка услуги 3
│   └── og-image.jpg            # Open Graph изображение
├── assets/                     # Дополнительные ресурсы
│   ├── fonts/                  # Локальные шрифты (если нужны)
│   ├── icons/                  # SVG иконки
│   └── favicon.ico             # Фавикон
├── sitemap.xml                 # Карта сайта для SEO
├── robots.txt                 # Инструкции для поисковых роботов
├── .htaccess                  # Конфигурация Apache (опционально)
└── README.md                  # Документация проекта
```

## Содержимое файлов

### index.html
Основной HTML файл с семантической разметкой, мета-тегами и структурой секций.

### CSS файлы
1. **variables.css** – CSS-переменные для цветов, шрифтов, отступов
2. **reset.css** – сброс стандартных стилей браузера
3. **base.css** – базовые стили для body, типографики, ссылок
4. **components.css** – стили компонентов: кнопки, карточки, формы
5. **layout.css** – сетка, контейнеры, flex/grid раскладки
6. **sections.css** – стили для каждой секции (hero, about, services и т.д.)
7. **responsive.css** – медиа-запросы для адаптивности
8. **utilities.css** – вспомогательные классы (margin, padding, text-align)

### JavaScript файлы
1. **main.js** – инициализация, управление бургер-меню, плавная прокрутка
2. **validation.js** – валидация формы консультации
3. **animations.js** – анимации появления элементов при скролле
4. **form-submit.js** – отправка данных формы на сервер

### SEO файлы
1. **sitemap.xml** – карта сайта для поисковых систем
2. **robots.txt** – инструкции для поисковых роботов
3. **.htaccess** – настройки для Apache (редиректы, кэширование)

## Порядок создания файлов

1. Создать директории: css, js, images, assets
2. Создать index.html с базовой структурой
3. Создать CSS файлы в порядке зависимостей
4. Создать JavaScript файлы с основной функциональностью
5. Создать SEO файлы
6. Добавить placeholder изображения
7. Протестировать в браузере

## Зависимости
- Google Fonts: Playfair Display, Open Sans
- Font Awesome или Feather Icons для иконок (можно использовать SVG)
- Нет внешних библиотек JavaScript для минимального веса

## Инструкции для реализации

1. **Начать с mobile-first подхода** – сначала стили для мобильных, затем медиа-запросы для планшетов и десктопов
2. **Использовать CSS-переменные** для согласованности дизайна
3. **Семантическая разметка** для доступности и SEO
4. **Оптимизация изображений** – сжатие, формат WebP
5. **Минификация CSS/JS** перед деплоем
6. **Тестирование** на реальных устройствах и в разных браузерах
