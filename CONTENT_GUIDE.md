# Руководство по замене контента для сайта психолога

Это руководство поможет вам заменить тексты, изображения и информацию на сайте психолога без технических знаний. Все изменения выполняются в файле `index.html` и папке `images/`.

## Структура контента на сайте

Сайт состоит из следующих секций:
1. **Шапка** - навигация и логотип
2. **Герой-секция** - главный заголовок и призыв к действию
3. **Обо мне** - информация о психологе
4. **Услуги** - перечень услуг и цены
5. **Преимущества** - почему выбирают психолога
6. **Отзывы** - реальные отзывы клиентов
7. **FAQ** - ответы на частые вопросы
8. **Контакты** - форма записи и контактная информация
9. **Футер** - контакты и ссылки

## 1. Как изменить информацию о психологе

### Имя и специализация
**Где находится:** В нескольких местах:
1. Заголовок страницы (вкладка браузера)
2. Логотип в шапке
3. Секция "Обо мне"
4. Футер

**Как изменить:**
1. Откройте файл `index.html` в текстовом редакторе (Блокнот, VS Code, Sublime Text)
2. Используйте поиск (Ctrl+F) для нахождения текста:

```html
<!-- Заголовок страницы (строка 6) -->
<title>Психолог Анна Петрова | Помощь при тревожности...</title>

<!-- Логотип (строка 64) -->
<a href="#" class="logo">Анна Петрова</a>

<!-- Секция "Обо мне" (строка 109) -->
<p>Я — Анна Петрова, дипломированный психолог с 10-летним опытом...</p>

<!-- Футер (строка 299) -->
<h3>Анна Петрова</h3>
```

3. Замените "Анна Петрова" на ваше имя везде, где встречается
4. Сохраните файл

### Фотография психолога
**Где находится:** Секция "Обо мне" (строка 105)

**Как заменить:**
1. Подготовьте свою фотографию:
   - Формат: JPEG или WebP
   - Размер: 600×800 пикселей
   - Качество: хорошее, но сжатое
2. Назовите файл `psychologist-photo.jpg`
3. Замените существующий файл в папке `images/`
4. Если имя файла отличается, измените путь в HTML:
   ```html
   <img src="images/ваше-фото.jpg" alt="Ваше Имя, психолог">
   ```

### Квалификации и образование
**Где находится:** Секция "Обо мне", список (строки 111-114)

**Как изменить:**
```html
<ul class="qualifications">
    <li>Магистр психологии МГУ</li>
    <li>Сертифицированный специалист по когнитивно-поведенческой терапии</li>
    <li>Член Ассоциации когнитивно-поведенческой психотерапии</li>
    <li>Прошла более 500 часов супервизии</li>
</ul>
```

Замените пункты списка на свои:
- Образование
- Сертификаты
- Членство в профессиональных ассоциациях
- Опыт работы

## 2. Как изменить услуги и цены

### Список услуг
**Где находится:** Секция "Услуги" (строки 125-148)

**Структура услуги:**
```html
<div class="service-card">
    <div class="service-icon">
        <img src="images/service-1.svg" alt="Индивидуальная консультация">
    </div>
```

**Как изменить:**

2. Измените описание (внутри `<p>`)
3. При необходимости замените иконку в папке `images/`
4. Для изменения цены добавьте её в заголовок или описание

**Пример ваших услуг:**
```html
<div class="service-card">
    <div class="service-icon">
        <img src="images/service-1.svg" alt="Индивидуальная консультация">
    </div>
    <h3>Индивидуальная сессия (50 минут) - 3 500 ₽</h3>

    <button class="btn btn-primary">Записаться</button>
</div>
```

## 3. Как добавить реальные отзывы

**Где находится:** Секция "Отзывы" (строки 202-219)

**Структура отзыва:**
```html
<div class="review-card">
    <p>"После 3 месяцев работы с Анной моя тревожность уменьшилась на 80%. Я снова могу спать спокойно."</p>

        <strong>Анна, 32 года</strong>

```

**Как добавить свои отзывы:**
1. Замените текст внутри `<p>` на текст отзыва
2. Замените имя и возраст в `<strong>`
3. Добавьте больше отзывов, скопировав блок `<div class="review-card">`

**Пример реального отзыва:**
```html
<div class="review-card">
    <p>"Благодаря консультациям я научился управлять своими эмоциями. Теперь я могу спокойно выступать на собраниях, хотя раньше это вызывало панику."</p>
    <div class="review-author">
        <strong>Дмитрий, 38 лет</strong>
    </div>
</div>
```

## 6. Как изменить мета-теги для SEO

**Где находятся:** В начале файла (строки 6-17)

**Что изменить:**
```html
<title>Психолог Анна Петрова | Помощь при тревожности и консультации онлайн</title>
<meta name="description" content="Профессиональный психолог с опытом работы 10+ лет. Специализация: тревожность, стресс, эмоциональные трудности. Индивидуальные консультации онлайн и офлайн. Запишитесь на первую встречу.">
<meta name="keywords" content="психолог, консультация психолога, тревожность, помощь при тревоге, психологическая помощь">
<meta name="author" content="Анна Петрова">

<!-- Open Graph -->
<meta property="og:title" content="Психолог Анна Петрова | Помощь при тревожности">
<meta property="og:description" content="Профессиональная психологическая помощь для тех, кто столкнулся с тревогой и стрессом. Консультации онлайн.">
```

**Рекомендации:**
- В `<title>` укажите имя, специализацию и город
- В `description` напишите краткое, но информативное описание (150-160 символов)
- В `keywords` добавьте 5-10 ключевых слов через запятую
- Для Open Graph используйте те же данные, но более коротко

## 7. Как изменить изображения

**Файл:** `images/hero-image.jpg`

**Требования:** SVG, 64×64 пикселей

**Требования:** 1200×630 пикселей, JPEG/PNG

## 8. Как изменить форму записи

**Где находится:** Секция контактов (строки 255-289)

   - Получите URL для отправки

## 10. Частые ошибки и их решение

### Проблема: Изображения не отображаются
**Причина:** Неправильный путь или имя файла
**Решение:**
1. Проверьте, что файл находится в папке `images/`
2. Проверьте имя файла (учитывайте регистр букв)
3. Проверьте путь в HTML: `src="images/имя-файла.jpg"`

### Проблема: Шрифты не загружаются
**Причина:** Проблемы с интернет-соединением
**Решение:** Используйте локальные шрифты:
1. Скачайте шрифты в папку `assets/fonts/`
2. Измените `@font-face` в `css/variables.css`

### Проблема: Форма не отправляется
**Причина:** Не настроен бэкенд
**Решение:** Настройте один из вариантов отправки (см. раздел 8)

### Проблема: Сайт выглядит неправильно на телефоне
**Причина:** Проблемы с адаптивностью
**Решение:**
1. Проверьте, что все файлы CSS загружены
2. Убедитесь, что не удалили медиа-запросы
3. Проверьте `css/responsive.css`

**Где:** Файл `css/variables.css`
**Что изменить:** CSS-переменные в начале файла:
```css
:root {
    --primary-color: #8B7355;
    --secondary-color: #F5E9D9;
    --text-color: #333333;
    /* ... */
}
```

### Изменение шрифтов
**Где:** Файл `css/variables.css`
**Что изменить:**
```css
:root {
    --font-heading: 'Playfair Display', serif;
    --font-body: 'Open Sans', sans-serif;
    /* ... */
}
```

### Добавление новых секций
1. Скопируйте структуру существующей секции
2. Вставьте перед закрывающим `</body>`
3. Добавьте стили в `css/sections.css`
4. Добавьте ссылку в навигацию

## Полезные советы

1. **Сохраняйте копии** перед внесением изменений
2. **Проверяйте в разных браузерах** (Chrome, Firefox, Safari)
3. **Тестируйте на телефоне** - важна мобильная версия
4. **Используйте валидатор** HTML: https://validator.w3.org/
5. **Проверяйте скорость загрузки**: https://pagespeed.web.dev/
