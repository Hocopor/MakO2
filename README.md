# Лендинг для психолога

Одностраничный адаптивный лендинг для психолога, специализирующегося на работе с тревожностью.

## Структура проекта

```
project/
├── index.html              # Основной HTML файл
├── css/
│   ├── style.css           # Основные стили
│   ├── variables.css      # CSS-переменные (дизайн-система)
│   └── responsive.css     # Медиа-запросы
├── js/
│   ├── main.js            # Основная логика (меню, форма)
│   ├── validation.js      # Валидация формы
│   └── animations.js      # Плавные анимации
├── images/                 # Изображения для сайта
├── assets/                # Дополнительные ресурсы (шрифты, иконки)
├── sitemap.xml            # Карта сайта для SEO
└── robots.txt            # Инструкции для поисковых роботов
```

## Технологии

- HTML5 (семантическая разметка)
- CSS3 (Flexbox, Grid, переменные)
- Vanilla JavaScript
- Mobile-first подход
- SEO оптимизация

## Дизайн-система

- **Цветовая палитра**: бежевые, нежные тона
- **Типографика**: система шрифтов для заголовков и текста
- **Компоненты**: кнопки, карточки, формы
- **Анимации**: плавные переходы и hover-эффекты

## Назначение

Лендинг предназначен для привлечения клиентов, ищущих психологическую помощь, с акцентом на конверсию в запись на консультацию.
